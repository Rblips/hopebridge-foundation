# 🌟 HopeBridge Foundation — Social Impact NGO Website

> **InAmigos Foundation Internship — Task 3: AI Website Generation**

HopeBridge Foundation is a modern, responsive concept NGO website dedicated to empowering underprivileged youth and strengthening communities through education, practical digital skills, career mentoring, and grassroots community initiatives.

---

## 🎯 Project Overview

This project was built to demonstrate practical, production-quality AI website creation. It features a rich design system, smooth animations, sticky glassmorphic navigation, interactive program detail modals, illustrative impact milestones, and client-side validated forms.

### ✨ Key Features
- **Modern UI & Design System**: Tailored Emerald & Teal social-impact color palette with glassmorphic cards and subtle shadows.
- **Sticky Navigation Bar**: Smooth scrolling to sections, active section tracking, mobile hamburger drawer.
- **Hero Section**: Engaging headline, clear mission subtext, CTA buttons, and interactive visual impact collage.
- **About Section**: Organization context, formatted **Mission** and **Vision** cards, and a 5-pillar **Core Values** grid.
- **Programs & Interactive Modals**: 4 core tracks (*Education Support, Digital Skills, Career Readiness, Community Development*) with expandable curriculum details and quick-volunteer actions.
- **Illustrative Impact Goals**: Transparent target benchmarks with progress meters and ethical disclaimer.
- **4-Step Methodology**: Interactive *"How We Work"* timeline (*Identify Needs → Build Programs → Engage People → Measure Progress*).
- **Volunteer Application Form**: Client-side validated form with field error handling, area of interest selector, and celebratory submission state.
- **Contact Desk & FAQs**: Demonstration contact channels, interactive FAQ accordion, and contact message form.
- **Fully Responsive**: Optimized for Mobile (375px+), Tablet (768px+), Laptop (1024px+), and Desktop (1440px+).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Local Run

```bash
# 1. Clone the repository
git clone https://github.com/<YOUR_USERNAME>/hopebridge-foundation.git

# 2. Navigate into the project directory
cd hopebridge-foundation

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit `http://localhost:5180/` in your browser.

### Production Build

```bash
npm run build
```
Output will be generated in the `dist/` directory, ready to deploy to Vercel, Netlify, or GitHub Pages.
